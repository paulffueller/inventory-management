Factory Inventory Management System

Architecture overview: a Vue 3 single-page app talking to a FastAPI service backed by in-memory JSON data.

System Architecture

Three tiers, all running locally. There is no database; data is loaded from JSON files once at server start.

Tech Stack

Small dependency footprint on both sides.

Frontend client/

  • Vue 3 (Composition API)
  • Vite 8 dev server and build
  • vue-router 4 for page routing
  • axios for HTTP
  • Custom SVG charts, CSS Grid layouts
  • Node 20.19+ or 22.12+

Backend server/

  • Python 3.11+
  • FastAPI with uvicorn
  • Pydantic 2 models
  • uv for environment and dependencies
  • Auto-generated docs at /docs

Testing and Tooling

  • pytest + FastAPI TestClient (tests/backend)
  • No frontend tests or linting configured
  • Claude Code agents, skills, and hooks in .claude/
  • scripts/start.sh and stop.sh

Data Flow

How a filter change in the UI becomes updated numbers on screen.

  1. User changes a filter The FilterBar updates shared refs in the useFilters composable: time period, warehouse, category, order status.
  2. View reacts and calls the API client The active view watches the filters and calls a method in client/src/api.js, which builds query params and omits any set to all.
  3. FastAPI route receives the request A route in server/main.py (for example GET /api/orders?warehouse=...&month=Q1-2025) reads the optional query params.
  4. In-memory filtering apply_filters and filter_by_month narrow the module-level lists from mock_data.py. Month and quarter matching uses the order_date field.
  5. Aggregation and validation Endpoints such as the dashboard summary compute totals, then Pydantic models validate and serialize the response as JSON.
  6. Client renders The view stores raw results in refs; computed properties derive chart series, table rows, and formatted values (USD or JPY depending on locale).

Design Notes and Constraints

Behavior to know about

  • Inventory has no time dimension, so it ignores the month filter.
  • Quarter mapping is hard-coded to 2025.
  • JSON edits require a server restart.
  • The API base URL is hard-coded in api.js.

Demo-grade shortcuts

  • CORS allows all origins.
  • Auth is mock user data only.
  • Purchase orders are read-only; no POST endpoint exists yet.
  • Backlog.vue has no route registered.

Internationalization

  • English and Japanese via useI18n.
  • Locale also switches currency (USD / JPY).
  • Strings live in client/src/locales/.
